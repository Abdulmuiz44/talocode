About Talocode

Open-source infrastructure for AI-native work — tools you can run locally, with a hosted Cloud layer when you need scale.

What we build

Talocode is an open-source organization building workflow layers for developers and AI agents: coding agents, memory, search, browser automation, MCP tooling, and more. Every product ships as something you can run yourself.

Talocode Cloud is the hosted API layer for the ecosystem. One TALOCODE_API_KEY unlocks product APIs with prepaid wallet billing — so you can start local and scale without rewriting your stack.

How to get started

  • Explore the GitHub organization
  • Create a Cloud key on the dashboard
  • Read the docs for API, MCP, and Skills
  • Follow product updates on @talocode
